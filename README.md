# 電波スコープ (denpa-scope)

Mac が受け取っている Wi-Fi の電波を、アナログメーターの針・オシロスコープ風の波形・周波数スペクトラムで見るツール。

- **メーター**: RSSI（受信強度 dBm）を、ばね＋ダンパで動く針で表示。直近10秒の最大/最小マーカー付き
- **波形**: 0.1 秒ごとの RSSI とノイズ。間の幅が SNR。10秒〜5分、一時停止、CSV 保存
- **周りの電波**: 約8秒ごとにスキャンし、2.4 / 5 / 6 GHz の各チャンネルの電波を「山」で描画。重なり（混み具合）も一覧に

**Web デモ**: https://denpa-scope.vercel.app （作り物のデータで動きます。実測は下の手順で Mac 上で）

## 使い方

```bash
npm start        # http://localhost:5730 （初回は Swift ヘルパーを自動ビルド）
npm run demo     # 作り物のデータで動かす（画面に「デモデータ」と出ます）
npm test
```

依存パッケージはありません（Node と Xcode Command Line Tools の swiftc だけ）。

## しくみ

```
helper/wifi-probe.swift  CoreWLAN で RSSI/ノイズ/速度/チャンネルを 0.1 秒ごと＋スキャン結果を JSON Lines で出力
server.js                ヘルパーを起動し、Server-Sent Events でブラウザへ中継。web/ を配信
web/lib/*.js             純粋関数（チャンネル↔周波数、束ねチャンネルの中心、統計、針の物理、山の形）= テスト対象
web/app.js               描画と配線（Canvas 2D）
```

## 制限

- macOS は位置情報の許可がないプロセスに **SSID / BSSID を渡しません**。名前は「取得不可」になりますが、チャンネル・幅・強さは実測です
- スキャン結果には OS のキャッシュが混ざるため、近くにもう無い電波が少しのあいだ残ることがあります
- 2.4 GHz の 40 MHz 幅は上下どちらに伸ばしているか取得できないため、端に寄らない側と仮定して描いています
